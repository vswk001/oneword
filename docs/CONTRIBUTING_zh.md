# 参与贡献 OneWord

感谢你对 OneWord 的关注！

## 如何贡献

### 报告问题

- 使用 [GitHub Issues](https://github.com/vswk001/oneword/issues) 报告 Bug 或提出功能建议
- 请尽量详细描述：复现步骤、期望行为、实际行为

### 提交代码

1. Fork 本仓库
2. 从 `main` 创建功能分支（`git checkout -b feat/my-feature`）
3. 进行修改
4. 使用规范的提交信息（`feat: add ...`、`fix: resolve ...`、`docs: update ...`）
5. 推送到你的 Fork（`git push origin feat/my-feature`）
6. 向 `main` 分支发起 Pull Request

### 提交规范

遵循 [Conventional Commits](https://www.conventionalcommits.org/)：

- `feat:` 新功能
- `fix:` Bug 修复
- `docs:` 文档变更
- `refactor:` 代码重构
- `test:` 测试相关
- `chore:` 构建、配置或工具变更

### 贡献方向

- **新模板** — 在 `templates/` 下添加项目模板
- **新技能** — 在 `skills/` 下改进或添加流水线技能
- **平台支持** — 在 `adapters/` 下改进平台适配器
- **Bug 修复** — 修复已有代码的问题
- **文档完善** — 改进 README，添加使用指南

### 代码风格

- 遵循项目现有模式
- 技能文件保持纯 Markdown 格式
- 模板必须开箱即用（`npm install && npm start`）

### 有疑问？

欢迎在 [Discussions](https://github.com/vswk001/oneword/discussions) 提问或分享想法。
