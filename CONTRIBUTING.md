# Contributing to OneWord

Thank you for your interest in contributing to OneWord!

## How to Contribute

### Report Issues

- Use [GitHub Issues](https://github.com/vswk001/oneword/issues) to report bugs or request features
- Include as much detail as possible: steps to reproduce, expected behavior, actual behavior

### Submit Changes

1. Fork the repository
2. Create a feature branch from `main` (`git checkout -b feat/my-feature`)
3. Make your changes
4. Commit with a clear message (`feat: add ...`, `fix: resolve ...`, `docs: update ...`)
5. Push to your fork (`git push origin feat/my-feature`)
6. Open a Pull Request against the `main` branch

### Commit Convention

Use [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation change
- `refactor:` code refactoring
- `test:` adding or updating tests
- `chore:` build, config, or tooling changes

### What You Can Contribute

- **New templates** — add a project template under `templates/`
- **New skills** — improve or add pipeline skills under `skills/`
- **Platform support** — improve adapters under `adapters/`
- **Bug fixes** — fix issues in existing code
- **Documentation** — improve README, add guides

### Code Style

- Follow existing patterns in the codebase
- Keep skills as pure markdown instruction files
- Templates must be runnable out of the box (`npm install && npm start`)

### Questions?

Open a [Discussion](https://github.com/vswk001/oneword/discussions) for questions or ideas.
